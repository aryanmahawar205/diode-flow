FILE 1: common/state_writer.py

A thread-safe shared state writer. Both sender and receiver pipelines
call this to report their status. The Streamlit UI reads from it.

Requirements:
- State file path: demo_output/transfer_state.json
- Write atomically: write to a .tmp file, then os.replace() into place.
  This prevents Streamlit from reading a half-written file.
- Use a threading.Lock() at module level to prevent concurrent writes.
- Expose these functions:

  init_state(transfer_id, file_name, total_windows, criticality,
             file_path, original_size_mb, compression_algorithm)
  -> Creates a fresh state dict and writes it.
     Sets overall_state = "RECEIVING".
     Initialises sender and receiver sub-dicts with all keys present
     (use 0 or null defaults — never missing keys).

  update_sender(windows_sent, total_packets_sent, bytes_transmitted_mb,
                compressed_size_mb, compression_ratio, elapsed_s,
                eta_str, status)
  -> Reads current state, updates sender sub-dict, writes back.
     Status values: "idle" | "compressing" | "sending" | "done" | "error"

  update_receiver(windows_decoded, total_packets_rx,
                  fountain_recovered_chunks, rs_recovered_chunks,
                  failed_chunks, elapsed_s, status,
                  sha256_match=None, storage_path=None)
  -> Reads current state, updates receiver sub-dict, writes back.
     Status values: "idle" | "receiving" | "decoding" | "verifying"
                    | "accepted" | "failed"

  set_overall_state(state_str)
  -> Updates overall_state field only.
     Valid values: "IDLE" | "RECEIVING" | "DECODING" | "VERIFYING"
                   | "ACCEPTED" | "FAILED"

  add_warning(message)
  -> Appends to warnings list (keep max 20 entries).

  add_error(message)
  -> Appends to errors list (keep max 20 entries).

  clear_state()
  -> Writes a blank state with overall_state = "IDLE" and all
     sender/receiver fields at zero/null defaults.

All functions must be safe to call from a subprocess (not just threads).
Use os.replace() for atomic writes. If the state file doesn't exist yet,
init_state() creates the demo_output/ directory automatically.

FILE 4: ui/streamlit_app.py

A clean, minimal Streamlit dashboard. Auto-refreshes every 1 second.

Requirements:

DEPENDENCIES — add to requirements.txt:
  streamlit>=1.35.0

AUTO-REFRESH:
  Use this pattern at the very bottom of the script:
    time.sleep(1)
    st.rerun()
  Wrap it in a try/except so Streamlit's StopException doesn't crash it.

LAYOUT:

  Header:
    Title: "Data Diode Monitor" in large text
    Subtitle: one line showing transfer_id (first 8 chars) | file name |
    overall state as a coloured badge:
      IDLE = grey, RECEIVING = blue, DECODING = orange,
      VERIFYING = yellow, ACCEPTED = green, FAILED = red
    Use st.markdown with inline HTML for the badge colour.
    Last updated timestamp: "Updated Xs ago" computed from last_updated.

  If overall_state == "IDLE" or state file missing:
    Show a single centred message: "Waiting for transfer to begin..."
    Still auto-refresh. Do not show any other panels.

  Otherwise show two equal columns: left = Sender, right = Receiver.

  SENDER COLUMN:
    Section header: "Sender"
    Status chip: same colour scheme as overall badge
    Four st.metric() widgets in a 2x2 grid:
      - Original size (MB, 1 decimal)
      - Compressed size (MB, 1 decimal) with delta showing ratio e.g. "3.7x"
      - Packets sent (integer, comma-formatted)
      - Data transmitted (MB, 1 decimal)
    Progress bar: windows_sent / total_windows
    Label below bar: "Windows: X / Y  |  Elapsed: Zs  |  ETA: T"
    Small text: compression algorithm + criticality level

  RECEIVER COLUMN:
    Section header: "Receiver"
    Status chip
    Four st.metric() widgets in a 2x2 grid:
      - Packets received (integer, comma-formatted)
      - Windows decoded (X / Y format)
      - Fountain recovered chunks (integer)
      - RS recovered chunks (integer) — highlight in orange if > 0
    Progress bar: windows_decoded / total_windows
    Label below bar: "Windows: X / Y  |  Elapsed: Zs"
    SHA-256 verification row: show nothing if null, green tick + "Verified"
    if True, red cross + "FAILED" if False.
    Storage path if accepted: show full path in st.code()

  BOTTOM SECTION (full width, only if warnings or errors exist):
    If errors: red expander titled "Errors (N)" containing each error as
    a bullet. Expanded by default.
    If warnings: yellow expander titled "Warnings (N)" containing each
    warning as a bullet. Collapsed by default.

  SIDEBAR:
    Title: "Controls"
    Button: "Clear State" — calls state_writer.clear_state() and
    st.rerun().
    Horizontal rule.
    Static info text explaining the one-way constraint in 2-3 lines.
    Small text at bottom: "Protocol v1.0.0"

STATE FILE READING:
  Read demo_output/transfer_state.json.
  If file does not exist: show "Waiting for transfer..." message.
  If JSON is malformed: show a small warning and wait — do not crash.
  Use a helper function load_state() -> dict | None that handles
  both cases cleanly.

ERROR HANDLING:
  Never let a missing key crash the UI. Use dict.get() with defaults
  everywhere. If a value is None or missing, show "—" in the UI.

STREAMLIT PAGE CONFIG:
  st.set_page_config(
      page_title="Data Diode Monitor",
      page_icon="🔒",
      layout="wide",
      initial_sidebar_state="expanded",
  )
